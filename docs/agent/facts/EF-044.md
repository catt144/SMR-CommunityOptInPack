- **A PROBE TALLY IS BUILD-SPECIFIC — never quote one build's count as the
  other's** (measured 2026-08-03, the MarsDebug `[install]` sitting). The
  eight `[install]` probes SKIP on every retail run ("introspection
  unavailable") and report only under a MarsDebug session after
  `SMRTest.EnableIntrospection(debug)` — that sitting read **87/87 PASS** on
  MarsDebug where retail reads **78/87**. The difference is not "MarsDebug is
  a better reading": at least one FIX genuinely behaves differently by build —
  `TechDescriptionBuilding` PASSes on MarsDebug and is a no-op on retail,
  because `T(id, text)` keeps the literal on a dev build and discards it in
  retail (F98's whole mechanism, `agent/bugs/F98.md`). ⚠️ Corollary: a
  MarsDebug pass on any loc/text-touching fix is NOT evidence about the
  retail player's experience; retail is the shipping truth.
