- **Engine predicates return TRUTHY NON-BOOLEANS — an `== true` test reads
  false on values that are semantically true.** Four instances, all MEASURED
  live (2026-08-10 `corun-batch-2` sitting unless noted):

  | call | returned |
  |---|---|
  | `UIColony:IsTechResearched("FrictionlessComposites")` | **`1`** (a number) |
  | `UIColony:IsTechDiscovered("FrictionlessComposites")` | **`163`** (a number) |
  | `el.broken` on a broken `TrackGridElement` | **a TABLE** |
  | `GetSpentTimeAverageInHours` (2026-08-05, F21) | **a `T()` object** |

- ⛔ **Rule for every reader and probe: test truthiness (`if x then`) or type,
  never `== true`.** A reader written `== true` against any of these prints a
  false negative forever and cannot print anything else — the F21
  `spent_time` reader-defect class, but for VALUES instead of names.

- ⚠️ The numbers are not documented meanings — `163` is presumably an index or
  count, but nothing here establishes what. Only the truthiness is the fact.
