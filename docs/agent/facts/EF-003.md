- `g_Consts` is a **GameVar** (`Lua\Modifiers.lua:427`) and does not exist while
  mods load — read it inside the patched function, never in apply(). `const` IS
  populated at that point.
  ⚠️ Precise form in [[EF-082]]: the KEY exists in `_G` from registration,
  holding `false` (`GameVar` rawsets it, `lib.lua:1069-1071`) — only the VALUE is
  unusable, which is why the game's own guard is the truthiness test
  `g_Consts and g_Consts[id]` (`Modifiers.lua:432`). So
  `rawget(_G, "g_Consts") ~= nil` is TRUE at apply time. ⛔ Do not read this
  bullet as saying the global key is absent — a self-check can ride on it.
