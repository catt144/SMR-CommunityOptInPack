- **SOURCE — iterator shape.** `TrackConnectedObjBase:ForEachConnectedTrack` enumerates only the
  current object's connector indices, resolves each `track_obj`, calls `track:GetDestStation(self)`,
  and invokes the callback with `(track, destination, ...)` (`Lua/TrainTransport.lua:68-80`). It has
  no recursion, visited set or deduplication. Normal completion and an empty connector set both
  return nil.
- **SOURCE — the broken edge is filtered.** `GetDestStation` returns false when
  `#elements_under_construction > 0` (`Lua/Buildings/Track.lua:339-354`). `BreakTrackElement` places a
  construction site with `track_obj = self` (`:623-645`); `TrackConstructionSite` is a construction
  `TrackGridElement`, whose `Init` inserts itself into that array (`Lua/Buildings/TrackElement.lua:
  185-188,620-630`). The helper consequently suppresses the callback for the edge repair code most
  needs to find.
- **SOURCE — physical endpoints survive.** `GetStartStation`/`GetEndStation` return
  `start_el.station`/`end_el.station` without testing construction, working state, damage or power
  (`Lua/Buildings/Track.lua:194-199`). Normal meteor damage excludes endpoints and station-owned
  elements (`Lua/Meteors.lua:713-725`), so physical endpoint ownership remains available while
  ordinary train traversal is blocked.
- **SOURCE — tunnels are separate edges.** Tunnel mouths use reciprocal `linked_obj` references;
  `TrackTunnelBase:GetConnectedTrack` resolves the far mouth's track (`Lua/Buildings/Tunnel.lua:
  23-30`; `Lua/Buildings/TrackTunnel.lua:7-9`). Vanilla's `disconnect_track_power` is the useful
  traversal precedent: mark a station visited, recurse through connected tracks, and separately
  recurse through a tunnel's linked mouth (`Lua/Buildings/Station.lua:1357-1371`).
- **INFERRED IMPLEMENTATION BOUNDARY.** Hub repair reachability needs its own visited-node and
  visited-track graph over physical connector tracks and valid tunnel links, explicitly retaining
  existing broken tracks and distinguishing them from unfinished new construction. Cached train
  routes and `CanTrainsRun` describe operability, not the owner's physical repair graph.
- **ISOLATION SEMANTICS.** A hub-rooted physical traversal excludes a complete remote component
  because no edge reaches it. `ForEachConnectedTrack` itself exposes no `isolated` flag: an
  unconnected station, an incomplete endpoint and a station whose first edge is broken can all
  produce no callbacks/nil. Helper emptiness therefore cannot prove isolation during damage.
- **CONTROL.** Slice `TrainTransport.lua:68-80`, `Track.lua:339-354` and
  `TrackElement.lua:185-188`; require respectively the `GetDestStation` call, the construction-array
  early return and construction-site insertion. The scoped check emitted `GraphFilterPremises=PASS`
  against archived 1.1.0.403908. A runtime smoke still owes hub component before/after break,
  independent remote component, tunnel pair and station cycle.
