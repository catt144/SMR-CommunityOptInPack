- **SOURCE — battery units.** `battery_max` is a modifiable `Drone` property, default
  `const.DroneBatteryMax`, property scale 100 (`Lua/Units/Drone.lua:9-11`); that constant is
  `800*100 = 80000` stored units (`Lua/_GameConst.lua:81`). `DroneEmergencyPower` is 6000 stored
  units (`Lua/__const.lua:632-637`). These are absolute thresholds, not fractions of `battery_max`.
- **SOURCE/MEASURED arithmetic — thresholds.** At `battery <= DroneEmergencyPower*2` (12000,
  inclusive), `CanTakeTaskOnTheWay` refuses work and `Idle` enters `EmergencyPower`
  (`Drone.lua:618-635,653-699`). `UseBattery` enters `EmergencyPower` at <=6000 and `NoBattery` at
  <=0 (`:1760-1783`). Against the default maximum these are 15% and 7.5%; increasing
  `battery_max` does not move them.
- **SOURCE — palette.** `Building.SetPalette(object, cm1, cm2, cm3, cm4)` validates the object and
  calls recursive colorization (`Lua/Buildings/Building.lua:736-748`;
  `CommonLua/Classes/Colorization.lua:846-858`). Vanilla recolours a recharge platform by obtaining
  four building colours and calling exactly `Building.SetPalette(platform, cm1, cm2, cm3, cm4)`
  (`Lua/Buildings/AttachedRechargeStations.lua:2-7,24-27`). The source structurally admits a valid
  colorizable Wasp but does not prove which `DroneJapanFlying` materials respond; that remains a
  visual probe.
- **SOURCE — control gate.** `Drone:CanBeControlled()` returns false only when disabled, rogue,
  embarking or disappeared (`Lua/Units/Drone.lua:2171-2173`). Both single-reassign and reassign-all
  update functions enable their buttons with `self:CanBeControlled() and tutorial2_enable`
  (`:1988-1991,2016-2020`), so a scoped false result greys both.
- **INFERRED/POLICY BOUNDARY.** A train-hub wrapper must call the captured original, return false
  only for a drone whose live `command_center` is the hub, and pass the original result through for
  every other drone. Identification by entity or a sweep of all Wasps would affect Japan-sponsor
  drones and is unsupported.
- **CONTROL.** Recheck the exact property/constant definitions, both inclusive comparisons, the
  four-argument platform palette call, `CanBeControlled` body and both button predicates in the
  archived build. Holding `battery = battery_max` establishes only threshold clearance; it does not
  prove the flight code never consumes or overwrites battery.
