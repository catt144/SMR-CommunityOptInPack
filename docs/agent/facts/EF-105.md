- **Why this fact exists.** On 2026-09-08 the owner planned to serve 1.0.7 players a frozen build through
  Steam's own branch delivery. The check refuted it; the owner ruled on 2026-09-16 that the finding lives
  here rather than only in the archived checklist item 118.
- **What the feature needs** (Steam Workshop Item Versioning): (1) the app has ordered branches, which it
  does (`Default Public Version`, `1.0.7 / Rollback version`, owner's screenshot 2026-09-08); and (2) the
  developer has ticked **"Enable Game Branch Versions"**. Only then is a player on an old branch
  automatically served the matching mod version from one listing.
- **Why (2) reads as OFF, both places sampled.** The author-side control is absent where Valve's
  documentation says it appears: the item's **Change Notes** list shows only Edit / Download /
  Revert-to-this-version, and **Edit Change Note** holds only Language, Description and Save.
- ⛔ **"Revert to this version" is NOT a substitute.** Its own tooltip says it makes that version live for
  *subscribers* — all of them, current-branch players included. It is exactly backwards for this purpose.
- **What follows for any old-branch build.** It ships as a manual download (the route taken: a GitHub
  Release of the frozen v5, linked from both store cards and the site). The best artifact is Steam's own
  `Download` button on that version's change note, byte-identical to what players received.
- ⛔ **The player must unsubscribe first.** Workshop, Paradox and `AppData/Mods` feed one dedup keyed on mod
  `id`, where the higher `version` wins (`Mod.lua:1779-1783`, 1.1.0 tree). A manual old build beside a live
  subscription is silently overridden, and the player believes it worked.
- ⚠️ **No console route exists.** The `AppData/Mods` scan sits behind `Platform.desktop` (`Mod.lua:1706`).
  Probably moot, since console players cannot opt into a Steam branch; unverified.
- **What would falsify this.** The "Enable Game Branch Versions" setting appearing in either author-side
  place above, or a player on the rollback branch being served an older mod version automatically. The
  setting is the developer's, so it can change without notice; re-check before planning around it.
