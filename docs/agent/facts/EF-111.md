- ⭐ **A "missing sound/FX" claim cannot be A/B'd by ear alone.** Worked out in
  the 2026-09-10 silent-FX sitting (`docs/agent/bugs/C77.md`, six units
  proven): every unit had OTHER sounds on `start`/`end` moments that play
  regardless, and twice the owner's ear heard those and reported "it works /
  no difference" while the actually-missing moment sound was still silent.
- **1. Learn the sound by hand-fire, next to the SELECTED object.**
  `PlayFX(<Action>, <Moment>, <actor>[, <target>])` fired next to a far object
  is inaudible (`loud_distance` ≈ 1200) and reads as "missing" even when it
  plays.
- **2. Prove it fires with a log-only hook, not the ear.** Hook the global
  `PlayFX` (save the original in a global, print action/moment/GameTime for
  the actor class, then pass everything through unchanged). Presence of
  `<moment>` lines versus only `start`/`end` lines is the verdict; the
  `start` lines are the control that proves the hook sees the path at all.
  Ask for a flush and wait before reading — `FlushLogFile()` lags console
  output by several seconds (`EF-047`).
- **3. Isolate by ear when the scene is busy.**
  `SetAllVolumesReason("tag", 0, 300, {[group]=true})` mutes every sound
  group but one; `SetAllVolumesReason("tag", false, 300)` restores
  (`CommonLua/Voice.lua:117-157`). A sound GROUP is not the same as a sound
  TYPE (the `Unit` group alone holds 25 types), so pair the mute with a
  STRICT hook that passes only the target moment plus every `end` call — the
  mute narrows what's audible, the hook narrows what's counted.
- **4. A/B a preset fix in-session by emptying `.Moments`.** Empty the
  preset's `.Moments` table in place (keep a copy in a global) and restore it
  afterward — a loaded preset persists until game quit, so a true "before"
  reading otherwise needs a full restart.
- **5. Check the moment TYPE and the PHASE before calling "no difference" a
  refutation.** FX rows can key on a specific moment id (`Hit` vs `Hit1`),
  and which phase carries the FX varies by unit (one of the six units' sound
  was on `Load` only) — a hook that misses the right moment/phase looks like
  a negative result without being one.
- Worked case this method proved: `docs/agent/bugs/C77.md` (five units,
  `tested-attended` 2026-09-10, `Fix_SilentHitMomentFX.lua`) plus its sibling
  C74. Do not edit that entry from here; this fact only cites it.
