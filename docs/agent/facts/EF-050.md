- **`SaveGame(display_name, { savename = <name> })` writes `<name>` to disk
  exactly as given.** MEASURED 2026-08-11 (`unattended-2` run 1, log
  `docs/archive/u2run1void_Mars.exe-20260811-01.17.34.log`):
  `SaveGame("U2RT1", { savename = "U2RT1", silent = true, no_screenshot = true })`
  returned **`err=false`** and produced a file called **`U2RT1`** — 54,311,838
  bytes, no extension — in
  `C:\Users\stkot\Saved Games\Surviving Mars Relaunched\76561198020568696\`.
  The following `LoadGame("U2RT1.savegame.sav", {})` returned **`File Not
  Found`**, and the run stopped there.

- ⛔ **The extension is the CALLER'S to supply.** Every previously-recorded save
  through this primitive happened to pass it already — `corun-batch-2`'s
  `CB2.SSave` defaults to the literal `"PT35FIXTURE.savegame.sav"` — so the
  logs read as though the engine appended one. It does not.

- ⚠️ **`err=false` is not a witness that the save is LOADABLE.** It says bytes
  were written; it says nothing about the name being one the load list or
  `LoadGame` can resolve. This is the same shape as [[EF-049]]: the primitive's
  own return value is weaker evidence than the file system plus a load-back, and
  a load-back is the only reading that would have caught this one.

- ⚠️ Resurrecting a proven primitive means resurrecting its **argument
  convention**, not only its body — the defect above came from copying the call
  and changing what was passed to it.
