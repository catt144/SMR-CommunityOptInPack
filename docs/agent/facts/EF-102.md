- **MEASURED, the tree, read from the live `ModTools\Src` on 2026-09-14.** Three
  `DefineClass` sites settle it:
  - `StorageDepot` — `Lua/Buildings/StorageDepot.lua:1`,
    `__parents = { "Building", "ResourceStockpileBase", "ShuttleLanding" }`. The common
    ancestor.
  - `UniversalStorageDepotBase` — `Lua/Buildings/StorageDepot.lua:329`,
    `__parents = { "StorageDepot" }`.
  - `MultiResourceDepotBase` — `Lua/Buildings/MultiResourceDepot.lua:8`,
    `__parents = { "StorageDepot", "MultiResourceCubeVisuals" }`.
  ⇒ **`MultiResourceDepotBase` is a SIBLING of `UniversalStorageDepotBase`, not a
  descendant.** An `IsKindOf(o, "UniversalStorageDepotBase")` guard is false for every
  object on the other branch.

- **MEASURED, both branches enumerated.** `UniversalStorageDepotBase`: **22** shipped
  subclasses. `MultiResourceDepotBase`: **5 distinct classes across 7 definition sites** —
  `UniversalFarmPlantStorageDepot`, `UniversalFungiStorageDepot`, `UniversalIngredientsDepot`,
  `UniversalMeatStorageDepot`, `UniversalProcessedFoodStorageDepot`. ⚠️ **7 files, 5 classes:**
  `UniversalFarmPlantStorageDepot` and `UniversalMeatStorageDepot` are each defined twice, once
  under `Lua/BuildingTemplate/` and once under `DLC/norman/Code/BuildingTemplate/` — a DLC
  override of a same-named base class. ⛔ A file count is not a class count here.

- **MEASURED, the two property names differ across the branches.** `storable_resources` is
  declared at `StorageDepot.lua:336`, which is **inside the `UniversalStorageDepotBase` block
  opening at `:329`** — it is NOT a `StorageDepot` property. `MultiResourceDepotBase` declares
  `storable_resource_groups` (`MultiResourceDepot.lua:12-13`) instead. `StorageDepot.lua:444`
  (`self.resource = self.storable_resources`) is likewise on the Universal branch only.
  ⇒ **`#storable_resources` discriminates ONE branch**, and any code reading it as "the depot
  shape" is blind to the other five classes.

- **WITNESSED IN PLAY, 2026-09-14 (smrtk 08, `reports/SMRTK_FULL_SITTING.md`).** The toolkit's
  `73_SMRTK_Infopanel.lua` `depot_read` guards on `UniversalStorageDepotBase` and therefore

  `selected_fill method=CheatFill object=UniversalIngredientsDepot(8590) status=OK
  valid_after=true` — no `before`, no `after`, no `resource`. The action is not wrong; its
  evidence is simply absent, which is the harder failure to notice.
