- **The defect this generalises, and it reversed a headline verdict.** The C47
  unattended leg (2026-08-15) predicted both Open Farm seed buffers would reach
  0 (P1). Its sampler polled `consumption_stored_resources` every 500 real ms;
  across three runs the sampled minima were 305/605/550 and 1661/1921/2041 of
  5000, zero-samples 0 in every run — and the leg recorded **P1 FAILED, "the
  buffer never reached 0"**. The same runs counted 2, 0 and 4
  `NotWorkingBuildings` adds on the draining farm, each carrying
  `reason=Consumption`.
- **The route that reverses it, re-derived at Src by the terminal audit.**
  `Building:GetWorkNotPossibleReason` returns `"Consumption"` only when
  `self:CanConsume()` is false (`Building.lua:612-613`), and
  `HasConsumption:CanConsume` is `not stored or stored > 0`
  (`HasConsumption.lua:366-368`) — so on a consumer with a live buffer the
  reason is coded to **stored == 0 exactly**. Every add with that reason IS a
  proof the buffer touched zero between two polls. A 9000 game-ms drain tick
  against 500 real-ms polling at 5x (2500 game ms per poll) leaves ample room
  for a zero-and-refill to fit entirely inside one polling gap.
  ⚖️ The reversal was forced by the **owner** during the attended sitting; the
  sitting then read 2 true-zero samples of 121 at 2-second polling, closing the
  loop with a direct observation.
- ⇒ ⛔ **THE HARNESS RULE.** A sampled series bounds nothing between samples:
  its minimum is an upper bound on the true minimum, its maximum a lower bound
  on the true maximum. Any claim of the shape *"it never reached X"* must come
  from something that fires AT X — an event subscription, a reason string coded
  to the boundary, a monotonic counter — never from the polled series alone.
  When an instrument is designed, pair every extremum it will report with such
  a witness; when a report is written, say *"the SAMPLED minimum was N over M
  samples at cadence C"*, never *"the minimum was N"*.
- ⚠️ Same family as the recorded-facts-are-claims-too rule and the C47 leg's own
  `rawget`-on-a-flattened-class defect: all three trusted *how* a value was read
  over *what* the reading can actually support.
