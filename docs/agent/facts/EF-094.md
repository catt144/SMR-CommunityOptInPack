- **SOURCE, the flag.** `AccountStorage.achievements.unlocked["<id>"]`, a plain boolean
  (`CommonLua/Classes/Achievement.lua:39-40`). A fresh account storage has it **empty**:
  `achievements = { unlocked = {}, progress = {}, target = {} }`
  (`CommonLua/Core/GlobalStorageTables.lua:214-220`).
- **MEASURED, the file** (read from a **copy**; the live file was never modified):
  `<Saved Games>\Surviving Mars Relaunched\<steamid>\account.dat`, 17,827 B, magic
  `BPUL`, header u32s `(92, 8, 0xFFFFFFFF, 0, 0, 1, 17635, 192)`. Bytes `0x5C..0x263`
  are **519 B of PLAIN Lua metadata** (`assets_revision = 33006`, `lua_revision = 403908`,
  DLC list, platform); the remaining ~97% is opaque — no zlib/zstd/LZ4 magic, and
  `achievements` / `unlocked` / an achievement id appear nowhere as bytes.
  ⭐ Useful side-fact: that metadata independently confirms the **runtime** `LuaRevision`
  is **403908** and tracks the build, unlike the mod-metadata `350453` of `EF-077`.
- **SOURCE, why a script is impractical.** `SaveLuaTableToDisk`
  (`CommonLua/Core/lib.lua:2175-2210`) is table → `"return "..ValueToLuaCode` →
  `CompressPstr` → `EncryptAuthenticated` (= `AESEncryptThenHmac`). The key derivation is
  plain Lua — `g_encryption_key = SHA256(GetAppId() .. (config.ProjectKey or "1ac7d4eb8be00f1bf6ae7af04142b8fc"))`
  (`:2171`) — but **both codecs are native**, so a script must reverse the AES/HMAC layout
  and the compression container out of the executable, with corruption risk on a live file.
  ⭐ `shouldCompress`/`shouldEncrypt` are both `not Platform.console and not Platform.developer`,
  so a **developer build writes the payload as plain uncompressed Lua**.
- ⛔ **THE RETAIL CONSOLE CANNOT CLEAR IT — it IS the mod sandbox.** `console.lua:36-56`:
  on `Platform.asserts or Platform.cmdline` the env passes through to raw `_G`, but on a
  `config.Mods` build `g_ConsoleFENV = LuaModEnv(...)` with
  `__index = function(env,key) if ModEnvBlacklist[key] then return end … end`. The engine's
  own comment says why: *"initialization is delayed because ModEnvBlacklist doesn't exist yet."*
- **SOURCE, blacklisted** (`CommonLua/Modding/Mod.lua:1281-1291`, `:1336`, `:1359-1360`):
  `AccountStorage`, `SetAccountStorage`, `SaveAccountStorage`, `InitDefaultAccountStorage`,
  `AsyncAchievementUnlock`, `CheatPlatformUnlockAllAchievements`,
  `CheatPlatformResetAllAchievements`. **NOT blacklisted:** `AchievementUnlock`,
  `GetAchievementFlags` — a mod may unlock and query, never clear.
- ⭐ **SOURCE, the local-only lever.** `AchievementUnlock(achievement, dont_unlock_in_provider)`
  — a **truthy second argument sets the local flag without calling Steam at all**
  (`Achievement.lua:140-152`).
- **SOURCE, sync is ONE-WAY: local → Steam, every launch.** `SynchronizeAchievements()`
  pushes `table.keys(AccountStorage.achievements.unlocked)` up
  (`Platforms/steam/SteamAchievements.lua:99-115`) and is called right after account
  storage loads (`CommonLua/AccountStorage.lua:81-84`). **Nothing reads Steam back.**
  ⇒ clearing local STICKS; a Steam-side reset is **silently undone on the next launch**.
- **SOURCE, the built-in reset is not dangerous, just useless here.**
  `CheatPlatformResetAllAchievements()` (`SteamAchievements.lua:159-163`) calls
  `SteamResetAchievements` over every preset — a normal supported Steam API operation, this
  app only, no saves or install touched. It fails for three other reasons: it clears **only**
  Steam, the next launch's sync re-pushes the local set, and it is blacklisted.
- ⭐ **THE WORKING TEST ROUTE — local only, zero Steam involvement, fully reversible:**
  **move `account.dat` aside → launch (the game regenerates an empty achievement table) →
  test → quit → move the original back.** The fix reads local state, so a clean local slate
  exercises the whole award path. Cost of the regenerate: account options reset (language,
  control scheme, shortcuts, tips), recovered by restoring the file.
- ⚠️ **Residual limit:** Steam keeps its own copy unless separately cleared, so a Steam
  *pop* may not re-fire. Everything before it is observable — use a log-only sink on the
  award path rather than relying on the toast.
- ⚠️ **For a real clean slate, ORDER MATTERS:** clear local first (move/delete `account.dat`),
  then the Steam side with an external tool; the in-game cheat is unreachable. Steam-first is
  futile.
- **SOURCE, vanilla defect noticed in passing (dev-cheat only, no player reaches it):** both
  `CheatPlatformResetAllAchievements` and `CheatPlatformUnlockAllAchievements` open with
  `if not Platform.steam or not IsSteamLoggedIn() then end` — an empty `then end` with no
  `return`, so the guard guards nothing and the body runs regardless.
- ⛔ Found 2026-09-13 pricing C92's playtest. ⚠️ Two claims were **corrected during the
  derivation** and the corrections are what is recorded above: the payload is NOT plain
  (only the metadata is), and the retail console does NOT run outside the mod sandbox.
