- ⭐ **A `.savegame.sav` is a `BPUL` (HPK) container whose METADATA BLOCK is
  plain text in the first ~2 KB.** A trivial ASCII-run regex over
  `open(p,'rb').read(200000).decode('latin-1')` yields, verbatim: `displayname`,
  `map`, `mission_sponsor_id`, `commander_profile_id`, `elapsed_sols`,
  `game_mode`, `playtime`, `os_timestamp` (unix), `orig_lua_revision` /
  `lua_revision`, `dlcs`, `active_mods` (each with `id`, `version`, `pdx_id`,
  `steam_id`, `source`), and `platform.cheats`. ⛔ **Read ~200 KB, not the
  first ~3 KB** — the `platform` block sits past 3 KB, and a short read
  produces a false negative that looks like proof.
- ⚠️ **`lua_revision` appears three times** — twice inside `active_mods`
  (each mod's own revision) before the save's own. **Match
  `orig_lua_revision` instead**, or a branch check reads a mod's revision and
  looks wrong.
- ⛔ **`platform.cheats` is NOT `CheatsUsed`.** A save with cheats disabled at
  save time simply has no `cheats` key in the `platform` block — absence is
  the reading, there is no `cheats = false`. That says cheats were not
  enabled AT SAVE TIME, nothing about whether the colony was ever cheated.
  The real taint record, `CheatsUsed` (`EF-095`), is readable only by
  DECODING the compressed save body — proven both ways against a positive
  control (owner sitting, `reports/SMRTK_SKELETON_SITTING.md`: "The fixtures'
  cheat flag IS readable from disk — measured, both sides"). Do not promote
  the plaintext hint to the decoded proof.
- ⭐ **Taint is a property of the LINEAGE, not of one save.** One colony's
  saves can read `CHEATS=true` at some sols and `unset` at others (measured:
  the 1.1.0 NASA/"USA" line reads `true` at Sols 18/22/31/35/47/76 and
  `unset` at 32/47(2)/56) — a later unset flag does not make that lineage
  clean. Compare every save in a colony's history, never a single save.
- ⛔ **WHERE THE SAVES ARE NOT.** `%APPDATA%\Surviving Mars\<steamid>\` holds
  real `.savegame.sav` files and is NOT the owner's save folder — it is an
  agent-backup/test set (owner, 2026-09-14, authority: *"agents constantly
  assume my saves are in appdata, they have never been there... that is not
  my user save folder"*). A directory listing there supports no claim about
  what colonies the owner has actually played.
- ✅ **WHERE THE SAVES ARE.** `C:\Users\stkot\Saved Games\Surviving Mars
  Relaunched\<steamid>` — the Windows **Saved Games** folder. The repo
  exposes it through git- and pack-ignored junctions (`a5f24bc`):
  `saves/game` → the live folder the game actually lists, `saves/backup` →
  `%APPDATA%\Surviving Mars\<steamid>` (deliberately kept: 1.0.7 reference
  saves, the C92 evidence save, `account.dat`), `saves/reporters/` a real

  leaves it invisible to the load list. Layout note: `docs/agent/WORKFLOW.md`.
