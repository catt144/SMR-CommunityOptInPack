- **MEASURED, the route.** `A:\SteamLibrary\steamapps\common\Project Spark\Packs\Shaders.fpk`
  extracts to **281** files of plain-text shader SOURCE (`.fx`, `.fh`, `.h`, `.hlsli`) — not
  compiled blobs. ⚠️ `tools/flpk_extract.py`'s `__main__` expects a root of MOD folders each
  holding `ModContent.fpk`, so pointing the CLI at a pack fails; import it and call
  `extract(fpk_path, out_dir)` directly. Same opener already proven on other packs:
  `EF-063` (`Local\<Language>.fpk`), `EF-085` (`Lua.fpk` / `Data.fpk` parity).
- **MEASURED, what the atmosphere system is.** Nine files, ≈147 KB: `AtmosphereScatteringModel.fh`
  (28,690 B), `AtmosphereComposition.fx` (25,499), `AtmosphereEpipolar.fh` (24,507),
  `AtmosphereEpipolar.fx` (22,567), `AtmosphereEpipolarRefinement.fx` (13,362),
  `AtmosphereCommon.fh` (13,026), `AtmosphereSimulation.fx` (9,732),
  `AtmosphereMultipleScattering.fx` (6,212), `AtmosphereDefinitions.h` (3,401).
  This is the code that renders the `phys_sky` presets `EF-100` depends on.
- **MEASURED, PlayStation paths ship in the PC source — but they are language shims.**
  `#ifdef PSSL` occurs **8** times; `Lang.fh:19-20` maps `__PSSL__` → `PSSL`. The bodies are
  portability adapters: 16-bit float type aliases (`FidelityFx_Denoiser_Common.fh:35-36`,
  "min16float* are DXC-specific 16-bit float types; alias to native PSSL half types"), wave
  operations and intrinsic syntax (`AutoExposure.fx:68`, `ContactShadows.fx:9`,
  `Blending.h:34`, `Common.fh:787`, `ffx_a.h:1245`, `NRD.hlsli:167`). ⛔ **None is a feature
  gate** — no PSSL branch disables or substitutes an effect.
- **MEASURED, the atmosphere shaders carry NO platform conditionals at all.** Every `#if` in
  `Atmosphere*.fx` / `.fh` / `.h` is a feature or quality toggle: `SKY_ONLY`, `MOTION_DATA`,
  `ENABLE_MULTIPLE_SCATTERING`, `EXTINCTION_EVAL_MODE` (`_EPIPOLAR` vs `_PER_PIXEL`),
  `LINEAR_DEPTH_MAP`, `ENABLE_FIX_DEPTH_BREAKS`, `SHOW_LIGHTING_ONLY`, `ENABLE_DEBUG`,
  `RENDER_STATE` ⇒ the sky math is platform-agnostic; any divergence lives in which defines
  and quality paths the engine compiles, which is C++.
- ⛔ **THE BOUNDARY — what this does NOT buy.** (a) The C++ that selects defines/quality per
  platform is not in the tree. (b) `Packs/ShaderCached3d12.fpk` is the compiled **d3d12** cache
  (decompressed and byte-searched in `EF-088`); **no console shader set ships to us**. (c) No
  PS5/Xbox binary is on disk and none ever will be. ⇒ A per-platform rendering difference can be
  *bounded* from here but never *decided*; treat any such attribution as INFERRED.
  Adjacent routes already recorded: `EF-089` (`EnumEngineVars("hr.")` for real exported names,
  `DlcMountFolder` as an untested shader-overlay route), `EF-088` (cache contents, one shader's
  byte-proven identity).
- **SOURCE, per-platform options ARE fully readable.** `CommonLua/Core/GlobalStorageTables.lua:110-211`
  (`DefaultEngineOptions`) gives each platform its overrides — **PS5 `GraphicsApi = "agc"`,
  PS5 Pro `"agc"`, Xbox Series X/S `"d3d12"`** (same API family as PC), with `VideoPreset`
  `PS5Quality` / `PS5Pro` / `XboxSeriesXQuality` / `XboxSeriesSQuality`; resolved in
  `Options.PickVideoPreset` (`Core/options.lua:324-344`), contents in
  `Lua/ProjectOptions.lua:78-190`. ⚠️ **`PS5Quality` is an ULTRA-tier preset** — Textures /
  Terrain / Effects / ViewDistance all `Ultra`, `ResolutionPercent` 100 — so "console runs low
  settings" is REFUTED, and `Effects = Ultra` means `FXDetailThreshold = 0` (nothing culled).
- **SOURCE NEGATIVE:** there is **no sky or atmosphere option at any quality tier on any
  platform** (the full set is Textures, Shadows, Terrain, Effects, ViewDistance, Antialiasing,
  Anisotropy, ResolutionPercent, Upscaling, Lights, Bloom, EyeAdaptation, Vignette,
  ChromaticAberration, ObjectDetail, SSAO, SSR, MaxFps), and `config.LightModelUnusedFeatures`
  is **unconditional** — `{ clouds, dist_blur_desat }`, no platform branch, `phys_sky` absent
  from it (`Lua/Config/config.lua:50-53`) ⇒ atmosphere is enabled identically everywhere in
  every layer we can see. ⛔ Falsifier: any platform branch reaching a `phys_sky` property, or
  a console shader set appearing in an install.
