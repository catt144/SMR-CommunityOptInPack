train spec `docs/agent/reports/TRAIN_LOGISTICS_DESIGN_20260917.md` §4.8–§4.10 and §10. Module

The D14 entry holds the dev build's audit residue (D14(h) is still open).

**Code.** `Code/Opt_TrainHub.lua` registers it and holds the build-menu lock. Its parts follow
it:
- `TrainHub_20_TrainHub.lua`: the building, upgrades and track work;

entities are `SMROptInTrainHub6`, `…Glass` and `…DomeGlass`. The parts always load, so a placed
hub works with the module off.
