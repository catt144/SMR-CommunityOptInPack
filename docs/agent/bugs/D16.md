### D16 — Station rows (design)  `[built — Code/Opt_StationRows.lua + StationRows_*.lua; dev-mod sittings passed live; the shipping battery is brief 35's]`

⚖️ **Owner rulings.** The rows on every station, with or without a hub, 2026-10-02: *"I want to give
the import / export / and sliders options even without the hub. Some people may never watn to use
the hub."* The settled row shape (four-state native cycle, thin slider), 2026-09-26. Module
shape at brief 34's checkpoint, 2026-10-02 (OI-41): one of three train modules, with **Station rows
forced on while the Train Hub module is on** (*"the stationrows needs to be forced if the hub is
on, I feel like without that it will cause issues"*). All recorded in the train spec
`docs/agent/reports/TRAIN_LOGISTICS_DESIGN_20260917.md` §4.7, §4.8 and §10 (grep `Brief 34's
checkpoint`).

**What it does.** Each resource row on a vanilla train station's panel cycles Balanced / Export /
Import / Not accepted, with a slider for the target. Hubless stations keep their own settings
(`SMROptIn_station_rows`). A station on a hub's network uses the hub's settings
(`SMROptIn_distribution`, D17), and those rows are part of the hub.

**Code.** `Code/Opt_StationRows.lua` registers it. Its parts follow it, flat, because a
`ModItemCode`'s file is its name (FIX_POLICY §8):
- `StationRows_10_TrainFloor.lua`: the transient claims; its standing hold serves D17.
- `StationRows_40_TrainDistribution.lua`: the rows, train views and desired amounts.
- `StationRows_45_TrainDistributionUI.lua`: the native row hook.

**The gate.** `D.RowsOn(st)` is true on a hub's network always. Hubless, it is true while
`StationRows` or `TrainHub` is active. It is read per call by 40's hubless paths and by 45's
`network()`. Off, `on_deactivate` re-applies every station, which restores the vanilla desired
amounts and leaves the stored rows in place, unused.

**Controls.**
- `tools/trains/hub/tests/module_gates_smoke.py` runs through the real `00_Core.lua`. It checks
  both modules off, StationRows on, live off, TrainHub forcing the rows, and the hub network
  with both off.
- Three mutations each fail at their own gate: the gate always open, TrainHub not forcing, and
  the hub network gated like a hubless station.
- `hubless_smoke.py` and `hubless_slots_smoke.py` hold the hubless behaviour.
