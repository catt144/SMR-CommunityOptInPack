**⚠️ Layout correction to the owner's ruling.** OI-41 chose "each module's parts in `Code/<id>/`".
That cannot ship. A `ModItemCode`'s file is `"Code/" .. name .. ".lua"` with `/` made `_`
(`CommonLua/Modding/ModItem.lua:164-168`), and `CodeFileName` is read-only and unused (`:103`).
Both portals force a SaveDef on upload, so a subfolder part would have dropped out of the `code`
list. The parts are therefore flat as `Code/<id>_<part>.lua`. That keeps the ruling's substance:
one Opt file per module, its parts as their own files, listed right after it. FIX_POLICY §8 and
the spec record the corrected form. doccheck's MODULE SETS and `upload_preflight.py` now fail an
item whose name does not derive its `CodeFileName`. Falsified with the original subfolder layout:
both went RED. The owner may veto the flat form, but no subfolder form exists.

## The gates

- **Rows.** `D.RowsOn(st)` is true on a hub's network always. Hubless, it is true while
  `StationRows` or `TrainHub` is active. It is read per call by 40's hubless paths (`station_rows`,
  `effective`, `Set`, `UnloadAll`, `local_train_view`) and by 45's `network()`. Turning the module
  off re-applies every station: the vanilla desired amounts come back, and the stored rows stay,
  unused.
- **Spoilage** (owner, OI-41: it goes with the hub). A station calls vanilla's
  `StorageDepot.SpoilStoredResources` while `TrainHub` is inactive. The hub always spoils.
- **Build menu.** `TrainHub` and `ElevatorDepot` off lock their template out (`Lua/X/BuildMenu.lua:731`,
  a locked template is not listed). Built ones keep working.
- **Without the framework** (the desk harnesses) the gates read open, as the dev mods behaved.

`tools/trains/hub/tests/module_gates_smoke.py` runs the real `Code/00_Core.lua` and the three Opt
files and drives the toggles as the engine does (`CurrentModOptions` + `OnMsg.ApplyModOptions`). It
covers both directions and the first mid-session enable. Five mutations (gate always open, no
forcing, hub network gated, spoilage ungated, lock removed) each fail **at their own gate**. A
harness error cannot pass as a rejection: the first draft was caught doing exactly that and fixed.
